# CustomPlugin

Custom plugin for private Minecraft server.

## Requirements

- Java 25
- PaperMC 26.1 (Minecraft 26.1)

## Features

- **Grief Prevention**: Cancels griefing from Creeper, Ghast, and Enderman
- Player death location is logged for administrator

## Configuration

Checkout [here](./CONFIGURATION.md)

## Build

Build steps:

1. Clone this repository.
2. Run `gradlew build`
3. Locate the `.jar` file in `REPO_DIR/build/libs/` directory

> NOTE: `REPO_DIR` stands for the path where you cloned this repository.
